### Usage

```js static
import CountryMap from 'src/components/graph/CountryMap'

<svg preserveAspectRatio="xMinYMin meet" viewBox="0 0 400 400">
  <CountryMap
    countryIsoAlpha2Code="US"
    extent={[[0, 0], [400, 400] ]}
    fill={_.constant('#34717c')}
    stroke={_.constant('#ffffff')}
  />
</svg>
```
