### Usage

```js
import { ChartContainer } from 'src/components/graph/ChartContainer'
```

The ChartContainer component acts as a container for the BarChart, ColumnChart, and LineChart components. It provides an optional title, and optional alert for the chart.

### Props

By default, the ChartContainer component renders no title and no alert. Listed below are all possible props, with their data types in parentheses:

title (string)  
bottomTitle (boolean)  
alert (string ('red', 'amber', 'green'))  
alertMsg (string)
