### Usage

```js
import { FocusBlurTextField } from 'src/components/shared/FocusBlurTextField'
```

Thie FocusBlurTextField component is a TextField component that includes event handler functions. These functions include onBlur, onFocus, onKeyUp, and onChange.

### Variations
Standard Text Field
```
<FocusBlurTextField />
```


### Customization
The event handler functions are customizeable and can be passed in as props.
