### Usage

```js
import ReadOnlyField from 'src/components/shared/ReadOnlyField'
```

The ReadOnlyField component creates a read-only style field container, which includes both a label and a value.

### Variations

Standard Single-field Container
```
<ReadOnlyField label="Name" value="hello" />
```


Large Single-field Container
```
<ReadOnlyField lg label="Name" value="hello" />
```
