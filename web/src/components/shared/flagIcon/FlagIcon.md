### Usage

```js static
import FlagIcon from 'src/components/shared/flagIcon/FlagIcon'
```

The flag icon renders a country flag based on its two letter ISO Alpha-2 code, passed in as the 'countryIsoAlpha2Code' prop.

### Variations
United States Flag
```
<FlagIcon countryIsoAlpha2Code="US"/>
```

South African Flag
```
<FlagIcon countryIsoAlpha2Code="ZA"/>
```
