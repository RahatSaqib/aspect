### Usage

```js
import { ReadOnlyField } from 'src/components/shared/ReadOnlyFields'
```

The ReadOnlyFields component creates a read-only style field container, which includes both a label and a value.

### Variations

Standard Container
```
<ReadOnlyField fields={[{label: 'Name', value: 'hello'}, {label: 'API Key', value: 'goodbye'}]} />
```
